# Rotate 2D Matrix

Rotate an `n x n` 2D matrix 90 degrees clockwise, in place.

## Files

| File | Description |
| --- | --- |
| `0-rotate_2d_matrix.py` | `rotate_2d_matrix(matrix)`: rotates the matrix ring by ring, swapping four cells at a time. Returns nothing. |

## Requirements

- Ubuntu 14.04 LTS, Python 3.4.3
- First line of every file: `#!/usr/bin/python3`
- Code style checked with `pycodestyle` (1.7.x)
- No modules imported

## Example

```
$ ./main_0.py
[[7, 4, 1],
 [8, 5, 2],
 [9, 6, 3]]
```
