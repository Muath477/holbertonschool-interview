# holbertonschool-interview

Solutions for Holbertonschool interview-prep algorithm projects.

## Projects

- [pascal_triangle](pascal_triangle/) - Build Pascal's triangle up to a given number of rows.
- [lockboxes](lockboxes/) - Determine if a set of interlocking boxes can all be unlocked.
- [minimum_operations](minimum_operations/) - Fewest Copy All and Paste operations to reach n H characters.
- [log_parsing](log_parsing/) - Read a log from stdin and print running statistics.
- [utf8_validation](utf8_validation/) - Determine whether a list of integers is a valid UTF-8 encoding.
